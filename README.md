# Perfume Library

이솝 향수 브랜드 콘셉트로 포토샵 디자인 작업 후 제작한 반응형 웹 퍼블리싱 작업물입니다.

---

## 📌 프로젝트 개요

- 프로젝트명: Perfume Library
- 제작 목적: 향수 및 바디 케어 브랜드 콘셉트 웹사이트 제작
- 제작 방식: HTML, CSS, JavaScript, jQuery 기반 정적 웹사이트
- 주요 목표: 반응형 레이아웃과 모바일 메뉴, hover 인터랙션 구현

---

## 💻 주요 구성

### 🧴 메인 비주얼

- 브랜드 분위기를 보여주는 메인 이미지 배치
- 메인 카피 문구를 활용한 첫 화면 구성

---

### 🛍 제품 소개 섹션

- 베스트 셀러 제품 소개
- 신제품 카드형 리스트 구성
- 이미지 hover 인터랙션 적용

---

### 💬 상담 안내 섹션

- 상담 영역 구성
- 이미지와 텍스트를 나누어 제품 소개 섹션과 시각적 차별화

---

### 📖 브랜드 스토리 섹션

- 향수 가이드, 향수의 역사 등 스토리형 메뉴 구성
- hover 시 사용자의 클릭을 유도

---

## 🛠 사용 기술

- HTML
- CSS
- JavaScript
- jQuery

---

## 📱 반응형 작업

- PC, tablet, mobile 화면에 맞춘 레이아웃 조정
- 모바일 환경에서 전체 화면 메뉴 구현
- 화면 크기에 따라 제품 섹션 배열 변경

---

## ✨ 개선 사항

초기 제작 당시의 구조를 최대한 유지하면서 hover 효과와 반응형 레이아웃을 개선했습니다.  
이미지와 버튼의 움직임을 부드럽게 조정하고, 화면 크기에 따라 콘텐츠가 안정적으로 배치되도록 CSS를 정리했습니다.
